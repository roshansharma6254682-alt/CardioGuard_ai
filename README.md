# CardioGuard_ai

## AI-Based ECG Heartbeat Classification

CardioGuard_ai is a machine learning project that uses ECG signals to classify heartbeats into two categories: Normal and Abnormal.

 Features
- ECG signal preprocessing
- Heartbeat segmentation
- Random Forest classification
- Abnormality probability estimation
- Interactive Gradio dashboard

 Technology Used
- Python
- NumPy
- SciPy
- Scikit-learn
- Gradio
- Matplotlib

 Dataset
MIT-BIH Arrhythmia Database (PhysioNet).

 Disclaimer
This project is for educational purposes only.
It is not intended for medical diagnosis.
